# 7.2 Registration and Studio Selection

> If after logging in you are **not linked to any studio**, the app will offer you to register — book your **first class**. The request goes through **administrator approval** at the studio.

---

## 7.2.1 New Client Registration

On the registration screen:

1. **"You are not registered with any studio"** ("Ви не зареєстровані в жодній студії"), below it — **"But you can book a class"** ("Але можете записатися на тренування") → the **"Book"** ("Записатися") button.
2. **"Enter your name"** ("Введіть ваше імʼя") → enter your name → **"Continue"** ("Продовжити").
3. **"Choose a studio"** ("Виберіть студію") → select a studio → **"Confirm choice"** ("Підтвердити вибір").
4. Choose a date (from today to next week) and a **class** from the list of available ones. The **"Start over"** ("Почати з початку") button resets the selection.
5. Confirm the booking — the request is sent to the studio administrator.

> If there are no available classes on the selected date — **"No classes available for booking"** ("Немає жодного тренування доступного для запису") is shown.

---

## 7.2.2 Request Being Processed

After the request is sent, the screen shows the status:

- **"Your request is being processed"** ("Ваш запит в обробці")
- **"The studio administrator will contact you to clarify the details"** ("Адміністратор студії звʼяжеться з вами для уточнення деталей")
- **"You will receive a notification about the status of your request"** ("Ви отримаєте сповіщення про статус вашої заявки")

> ℹ️ The administrator sees the new request in the admin panel and **approves or rejects** it. The client receives a push notification about the decision. After approval, the client gets full access to the app.

---

## 7.2.3 Choosing a Studio and Role

If you are already a client (possibly of several studios), after logging in the app will ask you to choose a context:

- **"Choose a studio"** ("Виберіть студію") → select a studio → **"Confirm choice"** ("Підтвердити вибір").
- **"Choose a client"** ("Виберіть клієнта") → select a role/client (shown as **"Name - Role"** ("Імʼя - Роль")) → **"Confirm choice"** ("Підтвердити вибір").

> If you have only one "client" at a studio — it is selected automatically.

> You can switch the studio or role later from the [Home screen](/en/mobile/home) using the **"Choose Studio"** ("Вибір студії") and **"Choose Client"** ("Вибір клієнта") buttons (shown only if you have more than one studio/role).
