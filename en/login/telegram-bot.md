# Telegram bot

> There is no separate **Телеграм-бот** (Telegram bot) tab in the settings. The QR code and banner for installing the app, the counters of registered clients and coaches and the message broadcast are on the [Settings → Mobile Application](/en/login/settings#mobile-application) tab.

## Bot functions

The Telegram bot has two functions:

1. **Delivering codes** for signing in to the app and confirmation codes for a guest, if a chat with the bot is linked to the phone number. If the bot did not deliver the code, the code is sent by the next channel in the order described in [Messages to clients](/en/pages/processing#_614-messages-to-clients).
2. **Delivering messages** to clients whose card is linked to one chat with the bot: visit reminders, messages about cancelled, cancelled-booking and moved sessions, booking confirmations, requests to rate the session. Channel order — [Messages to clients](/en/pages/processing#_614-messages-to-clients).

A chat with the bot is linked to an app account when the person shares their phone number with the bot in reply to the bot's request. The linked chat stays in the account, including after signing in to the app with an SMS code. A studio client card is linked to the chat through the app account with the phone number from the card.

To any other message the bot replies «Чат бот припинив свою роботу» (The chat bot has stopped working) with an offer to install the Fitshandler app (button **Встановити Додаток**, Install the app).

## The Fitshandler Telegram account

Clients whose card is not linked to a chat with the bot, or is linked to several different chats, receive Telegram messages from the Fitshandler account at the client's phone number, if the number is registered in Telegram. If a Telegram message cannot be sent, an SMS is sent — under the conditions described in [Messages to clients](/en/pages/processing#_614-messages-to-clients).

After a visit reminder or a rating request sent in Telegram, a client without the app receives a second message «Встановіть додаток Fitshandler <link>» (Install the Fitshandler app).
