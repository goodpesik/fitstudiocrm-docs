# Система підтримки

## Огляд

Вбудована система звернень підтримки для адміністраторів студії. Звернення створюється в адмін-панелі й передається сервісу підтримки Fitshandler (handler-support), який аналізує звернення і відповідає в зверненні: надає відповідь, ставить уточнювальне питання або заводить дефект.

Спілкування з підтримкою ведеться у вікні **Підтримка**, яке відкривається однойменною кнопкою в хедері адмін-панелі.

---

## Вікно «Підтримка»

**Доступ:** кнопка **Підтримка** в хедері — ролі **Супер Адмін** і **Адмін**. На кнопці відображається кількість звернень зі статусом **Нова відповідь**.

**Список звернень** — колонки **Тема**, **Статус**, **Пріоритет**, **Оновлено**. Кнопки **Новий тікет**, **Посібник користувача** (відкриває цю документацію) і **Запланувати консультацію**.

**Новий тікет** — поля **Тема \*** («Коротко опишіть проблему»), **Опис \*** («Детально опишіть проблему...»), **Пріоритет** (**Звичайний** / **SOS**), кнопки **Додати файли** і **Записати голосове**. Тема обовʼязкова. Запит описується текстом у полі **Опис** або голосовим повідомленням; достатньо одного з двох. Зображення або PDF без тексту чи голосового повідомлення опис не замінюють. Кнопка **Створити**; якщо тему не вказано або запит не описано — «Вкажіть тему та опишіть запит текстом або голосовим повідомленням». Після створення — «Тікет створено».

**Звернення** відкривається в тому самому вікні у вигляді листування. Тип повідомлення підтримки позначається: **Відповідь**, **Уточнення**, **Дефект**. Поле «Ваше повідомлення...», кнопка вкладення файлів, кнопка запису голосового повідомлення (мікрофон) і **Надіслати**. Повідомлення надсилається, якщо містить текст, файл або голосове повідомлення. Кнопка **Закрити звернення** закриває звернення («Тікет закрито»). Кнопка **Назад** повертає до списку.

Поле «Відповісти як підтримка...» і кнопка **Надіслати як підтримка** відображаються лише ролі **Супер Адмін** і лише для звернення, яке не закрите. Відповідь записується як повідомлення підтримки. Відповідати від імені підтримки може лише роль **Супер Адмін**; запит від будь-якої іншої ролі відхиляється з кодом 403. Статус звернення для цього запиту сервер не перевіряє.

**Статуси звернення:**

| Статус | Значення |
| --- | --- |
| **Відкрито** (`open`) | Звернення очікує обробки підтримкою |
| **Нова відповідь** (`awaiting_user`) | Підтримка відповіла або поставила питання. Коли користувач відкриває звернення, статус змінюється на **Відкрито** |
| **Вирішено** (`resolved`) | Звернення вирішено |
| **Закрито** (`closed`) | Звернення закрито |

**Оновлення.** Кількість звернень зі статусом **Нова відповідь** перевіряється кожні 10 хвилин. Якщо вона зросла, відображається вікно «Вам відповіла підтримка» з кнопкою **Зрозуміло**; вікно лише інформує і звернення не відкриває.

### Голосові повідомлення

Голосове повідомлення записується в новому тікеті (кнопка **Записати голосове**) і у відповіді у відкритому зверненні (кнопка з мікрофоном поруч із кнопкою вкладення файлів).

| Етап | Що відображається |
| --- | --- |
| Запис | «Іде запис», лічильник часу у форматі `хв:сс / 3:00` і кнопка **Зупинити**. Запис зупиняється автоматично через 3 хвилини |
| Після зупинки | Програвач для прослуховування запису, кнопки **Скасувати** і **Надіслати** |
| **Скасувати** | Запис видаляється, до звернення нічого не додається |
| **Надіслати** | Запис додається до файлів звернення або відповіді і надсилається разом із ними. Для нового тікета діють ті самі вимоги, що й для кнопки **Створити** |
| Надіслане голосове повідомлення | Відображається в листуванні як програвач |

- Для запису браузер запитує доступ до мікрофона.
- Голосове повідомлення є файлом звернення: на нього поширюються обмеження кількості й розміру файлів (див. [Обмеження](#обмеження)).
- Під час запису й до надсилання чи скасування кнопка запису недоступна.
- Закриття вікна, повернення до списку або перехід до іншого звернення видаляє незавершений запис.

| Ситуація | Повідомлення |
| --- | --- |
| Браузер не підтримує запис | «Ваш браузер не підтримує запис голосу. Опишіть, будь ласка, запит текстом.» |
| Доступ до мікрофона заборонено | «Доступ до мікрофона заборонено. Дозвольте доступ у налаштуваннях браузера або опишіть запит текстом.» |
| Запис не вдалося розпочати | «Не вдалося розпочати запис. Спробуйте ще раз або опишіть запит текстом.» |
| Запис перервано або він порожній | «Запис перервано. Спробуйте ще раз або опишіть запит текстом.» Такий запис не надсилається |

Решта вікна **Підтримка** під час запису і після відмови працює без змін.

## Обмеження

| Обмеження | Значення | Повідомлення |
| --- | --- | --- |
| Звернень на місяць на студію | Без обмеження | «Місячний ліміт тікетів вичерпано. Створити новий тікет можна буде наступного місяця.» (`TICKET_MONTHLY_LIMIT`) |
| SOS-звернень на місяць на студію | Без обмеження | «Місячний ліміт SOS-звернень вичерпано. Оберіть звичайний пріоритет або зачекайте до наступного місяця.» (`SOS_MONTHLY_LIMIT`) |
| Повідомлень користувача поспіль без відповіді підтримки | 3 | «Ви надіслали 3 повідомлення підряд. Дочекайтеся відповіді підтримки, щоб продовжити.» (`COMMENT_CONSECUTIVE_LIMIT`) |
| Файлів на звернення або відповідь | 10 (зображення, крім SVG, PDF, голосові повідомлення) | «До одного звернення можна додати не більше 10 файлів.» |
| Розмір файлу | 5 МБ | «Не додано N файл(ів): більші за 5 МБ.» |
| Загальний розмір файлів звернення або відповіді | 20 МБ | «Загальний розмір файлів одного звернення — не більше 20 МБ.» |
| Тривалість голосового повідомлення | 3 хвилини | Запис зупиняється автоматично |

Місячні ліміти рахуються з першого числа календарного місяця (UTC). На роль **Супер Адмін** місячні ліміти й обмеження повідомлень поспіль не поширюються.

## Обробка звернень

- Під час створення звернення й кожного нового повідомлення користувача сервер студії надсилає подію сервісу підтримки. Повторне надсилання того самого звернення не створює дубліката.
- Звернення з пріоритетом **SOS** обробляються щохвилини і першими; звичайні — кожні 10 хвилин.
- Рішення сервісу підтримки:

| Рішення | Дія | Тип повідомлення (`kind`) |
| --- | --- | --- |
| `answer` | Відповідь з інструкцією | `answer` |
| `question` | Уточнювальне питання | `question` |
| `escalate` | Заведено дефект | `defect_created` |

Відповіді надаються мовою звернення: текст кирилицею — українською, інакше — англійською.

### API сервера студії

**Маршрути адмін-панелі** (вхід користувача обовʼязковий):

| Метод | Шлях | Опис |
|-------|------|------|
| GET | /support/tickets | Звернення студії |
| GET | /support/tickets/:id | Звернення із повідомленнями та вкладеннями |
| GET | /support/unread-count | Кількість звернень зі статусом `awaiting_user` |
| GET | /support/limits | Місячні ліміти та залишок |
| POST | /support/tickets | Створити звернення `{subject, body, priority}` |
| POST | /support/tickets/:id/messages | Додати повідомлення та файли (до 10) |
| POST | /support/tickets/:id/reply-as-support | Відповідь від імені підтримки `{body}`. Лише роль Супер Адмін; для будь-якої іншої ролі — 403 |
| PATCH | /support/tickets/:id/status | Змінити статус звернення |

**Внутрішні маршрути** (для сервісу підтримки; обовʼязковий підпис HMAC):

| Метод | Шлях | Опис |
|-------|------|------|
| GET | /support-internal/ticket/:id?appId= | Повне звернення |
| POST | /support-internal/ticket/:id/comment?appId= | Повідомлення підтримки в зверненні |
| GET | /support-internal/attachment-data/:id?appId= | Вкладення в Base64 |
| GET | /support-internal/attachment/:id/file?appId= | Файл вкладення |
| GET | /support-internal/investigate/* | Читання даних студії для аналізу звернення |
| POST | /support-internal/actions/client-plans/close | Закриття абонемента клієнта |

### Підпис HMAC

Заголовки кожного запиту між сервером студії та сервісом підтримки:

```
X-Support-Product:    fitstudio
X-Support-Timestamp:  <unix-час у секундах або мілісекундах>
X-Support-Request-Id: <UUID>
X-Support-Signature:  HMAC-SHA256(secret, "METHOD\n/path?query\n{timestamp}\n{body}")
```

- Підписується повний шлях разом із параметрами запиту і тіло запиту без змін.
- Запит відхиляється (`401`), якщо підпис або час відсутні, підпис не збігається або час відрізняється від поточного більш ніж на 5 хвилин.
