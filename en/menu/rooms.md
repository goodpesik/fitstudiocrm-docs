# 3.5 Rooms

![](../../_media/rooms-1.png ':size=300x181')

## 3.5.1 Room card

> A room card contains:

- **Name**
- **Room colour** — the same shade as on the cards of workouts without a coach in the schedule.
- "Місткість: N" (capacity)
- **Buttons** (SuperAdmin and Admin roles):
  - **Delete** — disabled when the room has workouts (tooltip "Неможливо видалити. Існують тренування в цьому залі", cannot delete, there are workouts in this room). Deletion requires confirmation; afterwards "Зал успішно видалено" (room deleted) is shown.
  - **Edit** — opens the **Edit room** ("Редагувати зал") window.

> Next to the add button the plan limit is shown: "Зали: N / L · ще M" (rooms: used / limit · M left) or "Зали: N · без ліміту" (no limit), see [Plan and access](/en/login/billing).

## 3.5.2 Add a room

> The "+" button above the list of cards (SuperAdmin and Admin roles) opens the **Add room** ("Додати зал") modal window:

![](../../_media/room-2.png ':size=200x217')

**Contains:**

- **Name** ("Назва") — required, at least 3 characters.
- **Maximum number of people** ("Максимальна кількість людей") — required, from 1 to 100.
- **Choose the room colour in the calendar** ("Виберіть колір залу в календарі") — a palette of light shades (a 7×5 grid), the same as in the coach card. The room colour is used for workouts without a coach (for example, rentals). A colour saved before the palette existed is shown as the nearest palette shade.

Buttons: **Close** ("Закрити"), **Save** ("Зберегти").
